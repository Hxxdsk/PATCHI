使用教程

制作详情页

  1. 上传素材，选择模板。
  2. 点击图片框插入素材，选择「自适应」或「固定框」，点击文字编辑。
  3. 完成后导出图片或 ZIP。

制作主图

  1. 上传 Logo 和颜色图，颜色图按导入顺序排列，画布为 2500×2500。
  2. 选 Logo 后点击画布放置。再次点击 Logo 可拖动、缩放和旋转；点击空白取消选中。
  3. 按住鼠标拖动画布，Alt＋滚轮缩放；第一张完成后点击「批量贴标」，逐张微调。
  4. 点击 AI 处理，检查褶皱、光影和遮挡，可用保护画笔补充。按原格式、原文件名导出。

套详情图

  1. 上传已贴 Logo 的透明服装图与详情图，点击「批量套图」。
  2. 未识别处，选素材后点击对应衣料补充；用保护画笔保留前景。
  3. 选中页面后可「AI 处理本页」，或「撤回上一步 AI」。确认后导出。

AI 抠图

  1. 加入图片，首次使用先打开网站登录并保存。
  2. 启动自动抠图后可关闭面板，完成时右上角提示，点击关闭。

AI 设置与记忆

  1. 在 AI 设置添加 API。每个 API 独立检测与冷却，所有 API 共用一个模型。
  2. 一次检测所有 API，仅列出小型图像请求通过的模型。选择后所有任务统一使用该模型。
  3. 刷新保留本次内容。重新运行启动器会开始空白工作，Logo 库、尺寸记忆和加密 API 设置保留。

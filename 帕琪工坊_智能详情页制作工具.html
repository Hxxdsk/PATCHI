使用教程

制作详情页

  1. 在「素材」添加图片，在「模板」选择版式。
  2. 点击页面中的图片框选择素材，拖动图片调整位置，在右侧修改文字和尺寸。
  3. 点击「保存工程」保留进度；完成后按原文件名导出当前图片或全部 ZIP；可选择无损 PNG。

套详情图

  1. 点击「套详情图」，添加已贴好 Logo 的透明 PNG 和未贴标的详情图。优先用同一张原照片；允许一定色差和轻微姿势差异，以共同衣料特征确认位置。
  2. 选中左侧服装素材，点击详情图中对应的可见衣料。衣服部分被其他衣服遮住时，点击未被遮住的位置，程序会保留前景遮挡。
  3. 切换「看原图」检查效果。需要补充保留文字、手部等区域时，使用「保留原图画笔」涂抹。
  4. 出错可撤销套图或恢复原图。按原文件名导出当前图片或全部 ZIP；可选择无损 PNG，点击「返回详情页制作」回到原页面。

Logo 收藏库用于保存参考图；实际套图使用已贴好 Logo 的服装素材。完全被遮住的 Logo 不会覆盖到前景物体上。

AI 抠图

  1. 从素材库勾选图片加入队列，或选择电脑文件。选中的照片会发送到抠抠图服务。
  2. 首次使用免费自动模式时，点击「打开登录窗口」，在网站正常登录，再点击「完成登录并保存」。
  3. 点击「启动免费网站自动抠图」。透明 PNG 验证通过后自动回填，原有页面引用和位置保留。
  4. 失败时查看网页截图，确认登录、验证码和下载权限后重试。也可选「手动回收」，按导出原图、网站抠图、导入透明 PNG 的顺序操作。

官方 API 模式需要抠抠图密钥，费用按账号规则计算。结果须有真实透明区域，且分辨率不低于输入原图。

AI 信息识别

  1. 填写 Gemini 密钥，选择模型；可点击「检测当前 API Key 可用模型」。
  2. 上传、拖入或粘贴商品信息或尺码表截图，检查并修改识别结果。
  3. 点击确认导入对应页面。模型可用性和费用以自己的 Google 项目为准。

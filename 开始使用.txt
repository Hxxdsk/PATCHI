帕琪工坊 · 更新版 2026.10.13.7

本次更新
修复启动器双击无窗口 / 闪退：旧脚本有重复 UTF-8 BOM，导致 PowerShell 把 param 当成命令，程序目录参数无法绑定。已改为唯一 BOM，并增加启动监测、可读错误和启动日志。
主图画布固定 2500×2500，导入图片按比例居中铺到长边；透明图去掉外围全透明空边，保留全部可见内容。
Logo 放置后自动取消选中；默认鼠标按住拖动画布，点击已有 Logo 选中编辑，上方圆形旋转柄和角点可调整角度及大小，点击空白处取消选中。
跨姿势自动定位、Logo 框选和三点校准入口已取消。
套详情图与快速批量恢复 2026.10.12.4 的精准匹配引擎及工作区；保留色差、轻微姿势适配、素材删除、原名导出和高清不规则 Logo 轮廓。
AI 抠图官方 API 仍保持移除，只保留免费浏览器自动和手动回收。
新增独立的“制作主图”工作区。

启动方法
1. 更新前关闭旧 Python 助手，完整解压更新包到可写的普通文件夹。
2. Windows 双击“帕琪工坊启动器.exe”，也可双击“打开帕琪工坊.bat”。若仍打不开，运行“诊断启动器.bat”可直接调用源码并保留控制台报错。
3. 启动器检查程序文件、64 位 Python、四项依赖以及 Edge / Chrome。
4. 环境完整时自动启动“帕琪工坊.py”，并打开 http://127.0.0.1:8765/。
5. 缺少 Python 或依赖时，点击“下载并安装缺少组件”。由内置下载器及 pip 完成，不打开浏览器下载页。
6. 浏览器不自动下载。需要桌面版 Microsoft Edge 或 Google Chrome 120 或更新版本，建议最新版；安装后点“重新检查”。

系统要求
Windows 10 / 11 64 位，系统自带 Windows PowerShell 5.1 和 .NET Framework。
64 位 Python 3.10 或更新版本（包括 3.14），不设置版本上限。组件只设最低版本，较新且功能正常的环境直接通过。
无 Python 时，从 python.org 下载 Python 3.12.10 官方安装器，核对固定 SHA256 与官方数字签名。
仅当前用户安装到程序目录 .runtime/python，不改 PATH、不要求管理员权限。
缺少组件时在本目录 .venv 安装 numpy、opencv-python、Pillow、playwright；不运行 playwright install 下载浏览器。
本版同时修复缺少组件时传给 pip 的 requirements 文件路径参数。
失败或取消后可以重新检查、重试；未验证的下载文件不会当成完整安装器使用。
程序目录需可写，建议安装后保持路径固定；移动后专用环境不可用时会保留备份并重建。

制作主图
1. 点击工坊上方“制作主图”。左侧上传 Logo，推荐具有透明底的 PNG；JPG / WebP 也会按图案原样放置，其已有背景不会自动抠除。
2. 使用“＋颜色图”或把图片拖到画布，上传同款不同颜色图。图片按浏览器交付的选中文件顺序追加；右侧编号即后续导入顺序。每张适配到 2500×2500，按可见图片宽高比例等比居中，长边触及画布边缘。透明图仅去掉全透明的外边距，保留阴影和所有可见像素；白底 / JPG 图按整个文件范围适配。
3. 先点击左侧 Logo，再点击图片放置。可放多个 Logo（每张最多 8 个）；放置后会自动取消 Logo 和库图选中，便于看完整效果。再次点击放好的 Logo 显示编辑框；拖动图案移动，拖角点等比例缩放，拖上方圆形柄旋转（按住 Shift 以 15° 步进）。右侧可以输入 X / Y、宽高和角度。点击画布外或空白处取消选中。
4. 每个 Logo 的宽度按主图宽度比例自动记忆，下一款再贴时复用；不同画布像素尺寸按比例换算，保持 Logo 宽高比。
5. 按住 Alt + 滚轮，以鼠标为中心缩放画布；未选中 Logo 时直接按住鼠标拖动即可平移画布（包括在 Logo 上按住拖动）；点击已有 Logo 才选中。选中后，拖图案会移动 Logo，拖空白处会平移画布。按住空格可以在任意位置拖动画布，保留当前 Logo 选择。“适应画布”可以重新居中。视图缩放不改变图片、贴标坐标或导出尺寸。
6. 第一张图完成后点击“批量贴标”，把第一张全部 Logo 的位置、大小和角度覆盖同步到其他上传图。全部图片已适配成 2500×2500，相同画布坐标、大小和角度同步到其他图，Logo 保持比例。
   同步不自动识别衣服形状，适合构图和衣服位置基本一致的同款颜色图。同步后可在右侧切换各图，分别微调，不会改变其他图。
   再次批量会重新覆盖其他图的 Logo 布局；错误可在对应图点击撤销。
7. 调整好所有图后，点击“AI 处理全部主图”。复用软件已有的 Gemini 密钥和模型设置，无需另存一份主图密钥。
8. AI 逐张检查每个 Logo 的真实遮挡和光照。原图、当前贴标预览及 Logo 周围裁剪区域会发送至 Google Gemini；费用、配额与可用地区以自己的项目为准。
   Gemini 返回遮挡轮廓和光照参数；程序在本机用原始 Logo 像素合成，不让模型重新生成或更换品牌文字。
   衣服光照、阴影只改变 Logo 颜色值，不降低原 Logo 的透明度；只有确认的领口、抽绳等前景遮挡区域会恢复原衣服像素。
   Logo 周围区域之外的原图保持原像素。主图处理结果固定为 2500×2500，AI 检查缩略图不会拿来导出。
9. AI 完成后，逐张复核领口、抽绳、细小遮挡以及阴影。复杂遮挡不能保证自动准确。
   必要时点击“保留原图画笔”在遮挡位置涂抹，恢复原图细部；可调直径、点击撤销。此画笔也能在 AI 前使用。
   改变 Logo 位置、大小、角度或删除某层后，本图旧 AI 结果会失效，显示手动布局；再次点 AI 只处理未完成或已调整的图。
10. 网络、权限、配额或返回轮廓异常时，本图保留手动贴标，不会清空。其他图继续处理，失败原因可在右侧切换时查看；稍后重试会跳过已有 AI 结果。
    “完成当前图后停止”保留已完成结果。模型请求超时也会保留手动布局。
11. 可选择 PNG 或 JPG，批量导出 ZIP 或导出当前图。PNG 保留原透明背景；JPG 将透明区域转白底。
    “原文件名称”保留基本名称，只按选定格式改扩展名；“按导入顺序”输出 01、02、03…，超过 99 张按所需位数补零。
    同名文件在 ZIP 的“同名文件/2/”等子目录，避免覆盖。状态和检查说明放在“处理报告/主图报告.txt”。
    未 AI 完成的图允许导出当前手动贴标，会在状态和报告注明。
12. 左侧保存 / 读取“主图工程”，可恢复原始上传文件、2500×2500 布局、保护画笔与 AI 结果；密钥不会写入工程。旧 1 版主图工程按图片适配的统一比例和居中偏移迁移 Logo / 画笔 / AI 层，加载后请复核。
    “下一款”清空颜色图和本款编辑，Logo 库与尺寸记忆保留。退出前请保存需要保留的主图工程。

Logo 长期库
制作主图与套详情图收藏库共用当前浏览器的 IndexedDB，退出网页或软件不会主动清空。
点击 Logo 右上角 × 删除不需要的收藏；已贴入图片的 Logo 像素保留，可继续编辑与导出。
收藏和尺寸只保存在当前浏览器配置的同一站点地址；切换浏览器、隐私模式、清除站点数据或改用 localhost 地址可能看不到原库。
建议固定使用启动器打开的 http://127.0.0.1:8765/，保留 Logo 源文件备份。Logo 文件最多 5MB / 800 万像素。
主图最多 100 张；每张原图最多 26MB / 3200 万像素。大图及工程需要足够内存，工程文件读取上限 256MB。

精准套详情图
恢复 2026.10.12.4 的同源精准引擎和快速批量，不再使用衣身结构猜测位置。
添加已贴 Logo 的透明服装图和未贴标原始详情图，优先使用同一张原照片。
允许一定色差和轻微角度、缩放、局部姿势变化，以共同纹理、纽扣和缝线等可靠特征确认位置。
点击“批量套图”逐页遍历全部服装素材，缓存图片特征，每个组合采用约 1.8 秒软识别预算；可靠结果先套，识别不了的留待手动补充。
支持停止、重复运行避免叠加；素材右上角 × 删除不需要的图，不删除已有结果。
手动选中服装素材后，点击详情图中对应的可见衣料。识别失败不会强行覆盖。
只迁移 Logo 差异的真实轮廓，保留不规则、镂空及周围衣料。最终采样使用原素材，不把识别缩略图用于导出。
可用“看原图”、原图保护画笔、撤销和恢复原图。批量结束后请复核位置、边缘与遮挡。
默认按原格式和原文件名输出，无编号前缀或“_套图”后缀；可选择无损 PNG 保留基本名称。
同名文件放在 ZIP 分目录；报告在“套图报告/处理报告.txt”。JPEG / WebP 重编码仍可能有格式损失。
旧工程能打开，既有替换层保留旧效果；要用恢复后的精准算法，请撤销相应旧层重新套入。

后台助手与更新
启动成功后，启动器关闭，Python 助手继续后台运行；关闭网页不等于关闭助手。
同版本再次启动会复用助手；旧版或其他程序占用 8765 时会提示，不关闭无关进程。
更新前请退出本目录旧“帕琪工坊.py”；必要时在任务管理器核对命令行再结束相应进程。
必须完整更新主 Python、patchi_mainphoto.py、patchi_samephoto.py、patchi_batch.py、HTML 和 EXE。旧 patchi_pose.py 不再需要，本包不包含。
启动器早期日志在 .runtime/launcher.bootstrap.log，错误原因在 .runtime/launcher.failure.txt。正常日志在 .runtime/launcher.log、helper.out.log、helper.err.log；原有抠图登录状态与 Gemini 加密配置不会主动删除。
启动器源码在“启动器源码”。其他系统可以手动安装 requirements_套图.txt，配置 PAQI_BROWSER_BIN 为已有 Chromium 系浏览器路径后运行“帕琪工坊.py”。

帕琪工坊

启动
完整解压到可写文件夹，双击「帕琪工坊启动器.exe」。环境齐全时自动打开网页。
缺少 Python 或组件时点击内置下载安装。支持 64 位 Python 3.10 及更新版本（包括 3.14），组件不限制最高版本。
浏览器请自行安装桌面版 Edge / Chrome 120 或更新版本。
打不开时运行「诊断启动器.bat」，查看控制台与 .runtime 日志。
更新前先关闭旧 Python 助手，替换完整文件夹；不要只复制 EXE。

制作主图
1. 上传 Logo 到左侧长期库，上传同款不同颜色图，右侧按导入顺序切换。
2. 画布可随时选择「2500×2500」或「原分辨率」，贴标位置和大小同步换算。2500 模式等比居中并去除外围全透明空边；原分辨率保留完整宽高与透明边缘。Logo 输入支持最多 3200 万像素、128MB，不再限制为 5MB。
3. 选 Logo 后点击画布放置。再点击 Logo 可移动、缩放、旋转；点击空白取消选择。
4. 按住鼠标拖动画布，空格拖动同样可用；Alt＋滚轮缩放预览。
5. 第一张贴好后「批量贴标」，逐张微调。默认「本地光影融合」不耗 API，保留 Logo 原始像素和不透明度；生成建议后逐张预览并应用。
   制作主图中的 Gemini AI 已移除。本地光影建议和原图保护画笔保留；未确认建议不会导出，应用后可以撤销。
   自动褶皱与遮挡处理请从主页打开「外部批量贴标」，不再占用 Gemini API。
6. 按原格式、原文件名导出，输出 2500×2500 / 原分辨率。JPEG 白底，PNG / WebP 保留透明背景。

外部批量贴标（独立入口）
1. 主页面点击「外部批量贴标」，打开入口中的「安装与使用教程」。也可以离线打开 ComfyUI部署教程.html。
2. R7 1GB / 16GB 电脑使用 CPU 模式。运行安装外部贴标_CPU.bat，完成后运行外部贴标环境中的启动脚本。模型与组件仅安装到独立外部环境，首次需网络。
3. 输入 http://127.0.0.1:8188 并检查。也可连接局域网或受保护的远程 ComfyUI。
4. 读取制作主图的当前贴标快照，或直接上传颜色图及一个 Logo，首图定位后同步。每个 Logo 选择胸前或内侧领标。
5. 开始后顺序处理局部位置、相对深度、遮挡、褶皱与光影，保留原 Logo 像素。可返回工坊或立即停止；只取消本批次，不全局中断其他 ComfyUI 任务。
6. 细抽绳、低反差领口可能识别不全，需逐图复核。勾选已复核的图后按原格式原名导出。外部成品不自动覆盖主图编辑器，避免结果混用。
7. 刷新保留本次内容和外部任务；重启工坊助手前先导出。安装脚本、节点、模型和接口说明见完整教程。默认不使用老 AMD 显卡，不需要扩散大模型或 Gemini 密钥。

制作详情页
选择模板、上传素材，点击图片框插入；图片只设置自适应或固定框。点击文字编辑，完成后导出。
图片页单列超过 1 行、双列超过 2 行时，导出自动按每张 1 行裁剪（单列 1 图、双列 2 图），尾行保留不足的图片。当前页拆成多张时打包 ZIP，按编号排序。

套详情图
上传已贴好 Logo 的白底或透明服装图与未贴标详情图。点击「批量套图」，未识别处选素材后点击衣料补充。白底会自动排除边缘连通背景；复杂背景可先抠图或手动框选。
使用原精准引擎；适配一定色差和轻微姿势差异，优先使用同源照片。
选择页面后「AI 处理本页」，不会处理其他页；「撤回上一步 AI」恢复处理前图层，保留后续手动图层。
用原图保护画笔补充前景遮挡，确认后导出。

AI 抠图
加入图片，首次先登录网站并保存，启动自动抠图。处理时可关闭面板或刷新；完成后右上角提示，点击关闭。
失败时核对网站登录、验证码与下载权限，也可手动回收透明 PNG。

AI 设置
全部 Gemini 功能共用「AI 设置」，支持 AQ. 等密钥格式。添加多个不同项目的 API 后，一次检测全部 API。
检测并行读取模型目录，不再逐模型发送测试生成请求。目录可见不能证明图像兼容性、实时速率或剩余额度，实际任务会验证权限和额度并轮询。商品信息、尺码识别、细节文案、套图 AI 和衣物轮廓各自选择并自动记忆模型。关闭软件再启动也保留，不随新工作清空。
每个 API 独立冷却，权限不足、额度耗尽或不支持当前模型的 API 会跳过。
达到速率上限时自动尝试兼容 API；单张任务固定所选模型；限流只轮换 API，模型、图片和任务编号保持不变。处理期间换模型或刷新不影响当前任务。网络超时不自动重复提交。
任务窗口实时显示当前阶段、模型、API、等待秒数和轮询记录；认证失效、权限不足、额度限制会及时提示。限流时切换其他 API，全部暂不可用时最多短暂冷却，随后停止并保留原贴标。项目额度可在 Google AI Studio 查看。
点击任务窗口或主图上方「立即停止」会立即结束本地等待；已提交给 API 的请求可能仍在远端处理，迟到结果不会应用。等待期间可切换颜色图、缩放和拖动画布，或返回工坊使用其他功能。
模型拒绝结构化输出约束时会尝试一次兼容 JSON 格式。无效褶皱或过度擦除建议会保留原标识并提示；请复核后应用。
密钥可用 Windows 当前用户 DPAPI 加密保存；不写入图片或工作内容。图片会发送到 Google 进行分析。
开发修改：所有提示词和结构化输出格式在 patchi_ai_prompts.py；API 池和任务调度在 patchi_ai.py。

内容记忆
刷新保留本次的图片、贴标、页面和未完成 AI 任务。关闭网页后，通过同一地址重新打开也可继续。
重新运行启动器开始新的空白工作；Logo 库、Logo 尺寸记忆、加密 API 设置保留。
长期库与工作记忆都使用当前浏览器站点存储，请使用同一浏览器；清除站点数据会清除本地素材。
素材库可一键清空；已放置的主图 Logo 和已套入的详情图结果保留。
没有手动保存 / 读取工程入口。

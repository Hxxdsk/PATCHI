帕琪工坊 · 更新版 2026.10.12.5

启动方法
1. 关闭旧版助手，完整解压更新包到可写的普通文件夹。
2. Windows 双击“帕琪工坊启动器.exe”，也可以双击“打开帕琪工坊.bat”。
3. 启动器检查程序文件、64 位 Python、四项依赖，以及 Edge / Chrome。已有可用的 Python 3.14 不会被提示重新下载 Python。
4. 环境完整时自动启动“帕琪工坊.py”，并打开 http://127.0.0.1:8765/。
5. 如缺少 Python 或依赖，点击“下载并安装缺少组件”。下载由启动器及 pip 内部完成，不会打开浏览器下载页面。
6. 浏览器不自动下载。请自行安装桌面版 Microsoft Edge 或 Google Chrome 120 或更新版本，建议使用最新版；安装完成后点“重新检查”。

系统要求与环境管理
支持 Windows 10 / 11 的 64 位系统，需要系统自带的 Windows PowerShell 5.1 和 .NET Framework。
支持 64 位 Python 3.10 或更新版本（包括 3.14），不设置版本上限。已有可用环境会优先复用。
缺少 Python 时，从 python.org 下载 Python 3.12.10 官方安装器，并验证固定 SHA256 与官方数字签名。
安装到本目录 .runtime/python，仅当前用户安装，不改 PATH、不要求管理员权限。
组件取消版本上限，高于最低版本且能够正常导入、具有所需功能时直接通过。
缺少运行依赖时，在本目录 .venv 安装 numpy、opencv-python、Pillow、playwright；不会运行 playwright install 下载浏览器。
失败或取消后可点击“重新检查”重试。部分下载不会被当成完整安装器使用；已验证安装器可以复用。
程序目录应可写。安装后建议保持目录固定；移动目录导致专用环境不可用时，启动器会保留备份并重建环境。

后台助手
启动成功后，启动器关闭，Python 助手继续在后台运行。
再次双击启动器会检查环境并复用同版本助手，重新打开网页。
旧版或其他程序占用 8765 端口时会提示，不会自动关闭无关进程。
关闭网页不等于关闭后台助手。更新程序前，请退出正在运行的旧 Python 助手；必要时在任务管理器中根据进程命令行确认本目录的“帕琪工坊.py”，再结束该进程。
日志在 .runtime/launcher.log、.runtime/helper.out.log、.runtime/helper.err.log。

套详情图
1. 导入已贴好 Logo 的服装图（透明图或干净白底、黑底图），再导入未贴 Logo 的原始详情图。素材右上角 × 可以删除不需要的图；已套入的结果保留，可继续撤销或导出。
2. 优先使用同一原照片；支持有一定色差、轻微角度／缩放和局部姿势变化的同一件衣服。选中左侧素材，点击详情图对应衣服未被遮住的衣料。
3. 会先进行衣料色差补偿，利用分散的可靠特征点确认位置，并约束局部校准的幅度和拉伸程度。
   本版只迁移 Logo 变化轮廓，保留镂空、不规则形状和周围详情图像素，不再按整块矩形衣料覆盖。
4. 高分辨率素材按需要进行一次面积采样；配准缩略图和检测模糊图不会用于最终输出。
5. 用“看原图”核对结果。文字、手部或前景需要额外保留时，用“保留原图画笔”。
6. 匹配失败时不会覆盖；可撤销最后套图或恢复本页原图。

跨姿势套详情图
本版新增独立 Logo 迁移，不把素材的衣料、褶皱和背景覆盖到目标图上。
正面羽绒服／夹克，存在可识别领口、中央拉链和至少三个衣身分区时，可自动进行跨姿势定位；例如大图黑底已贴标服装到小图白底未贴标服装。
衣服更换姿势、帽领角度、袖子位置或衣身分区高度时，按衣服自身结构映射 Logo 位置和大小。
自动模式优先保留原照片定位；低分辨率详情图上确认衣身结构已变化时，会优先独立 Logo 迁移。也可直接选择“跨姿势 · 只迁移 Logo”。
彩色徽标会尝试自动提取。纯白、纯黑、单色图案或提取不完整时，选中素材，点击“标记素材 Logo”，紧贴图案拖出框；可添加多个框。
点击“预览提取”检查透明图中只有 Logo；误框入衣料时请重选。“自动识别 Logo”可帮助填入彩色徽标框。
结构无法确认或非正面羽绒服时，点击“跨姿势位置校准”：先在素材上依次点击 3 个分散点，再在详情图按同一顺序点击相同结构。
建议领口拉链、右侧肩缝、下摆拉链。三个点不要位于同一条直线上。确认后只迁移独立 Logo。
袖部、帽领、侧面、遮挡严重或变化更大的姿势，建议手动标记和校准，不能只凭颜色保证正确位置。
自动结果均提示复核；原图保护画笔可以保留手部、文字等遮挡。必要时撤销并重新校准。
Logo 标记随套图工程保存；“清除 / 重选”后确认可取消标记。
目标图仍以原尺寸输出。229×293 等小图中的 Logo 也只能占对应像素，不会强制放大整张详情图。

快速批量套图
点击套详情图上方“批量套图”，程序会逐页遍历当前所有上传的服装素材，不依赖当前选中哪一张素材。
每张图只准备一次纹理与衣身结构，之后重复使用；识别图仅用于定位，最终 Logo 仍取自原始素材，输出保持详情图尺寸。
每个组合使用约 1.8 秒的软识别预算，不执行耗时的多尺度模板搜索；单次原生算法和原尺寸合成可能超过预算。
快速可靠的匹配立即套入；跨姿势可复用独立 Logo 和衣身结构。不确定、结构不足或没有可见 Logo 变化的组合跳过；随后选中素材手动点击对应位置补充。
同一素材在一个页面最多快速处理两处位置，更多位置可继续手动补充。
跨姿势若多个素材同样匹配目标衣身且难以区分，批量会跳过，以免贴错品牌；请手动选择素材并补充。
已套入同一素材的页面组合会跳过，避免重复叠加。保护画笔会继续保留指定原图区域。
批量过程中可点击“停止批量”；当前一步完成后停止，已完成结果保留。重新开始会遍历尚未套入的组合。
进度与逐页报告会显示匹配或跳过原因。批量结束后请复核位置、边缘和遮挡关系。

输出命名与格式
默认“原格式 · 保持原文件名”，不加编号、前缀或“_套图”后缀。
例如“产品详情.jpg”输出仍是“产品详情.jpg”，“产品详情.png”输出仍是“产品详情.png”。
JPEG 和 WebP 按最高质量重新编码，仍可能有格式本身的损失；需要无损保存合成像素时，选择“无损 PNG · 保持原名称”。
PNG 模式保留原基本名称，仅将非 PNG 文件的扩展名改为 .png。
全部 ZIP 中，同名文件放进“同名文件/2/”等子目录，文件自身保持原名，避免解压覆盖。
报告放在“套图报告/处理报告.txt”；未处理页面按原图导出。
浏览器对下载目录中已有的同名文件可能自行增加 (1) 等编号，这由浏览器管理。

更新替换
建议完整解压使用本包，不只替换 HTML。必须同时更新主 Python、patchi_samephoto.py、patchi_pose.py、patchi_batch.py、HTML 和 EXE。
原有工程、Logo 收藏和 %LOCALAPPDATA%/帕琪工坊 内的抠图登录数据不会主动删除。
旧套图工程可以读取。旧工程已保存的替换层保持旧效果；要应用新轮廓算法，请撤销旧套图层后重新处理。

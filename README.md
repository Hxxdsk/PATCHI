## 制作主图

上传颜色图与 Logo，在画布贴标，第一张完成后批量贴标，再逐张微调、AI 处理和导出。

画布上方可随时选择「2500×2500」或「原分辨率」。原分辨率保留每张图完整宽高和透明边缘；2500 模式等比居中。切换时同步换算 Logo 位置、大小与保护笔画，旋转角度保留。AI 处理中选择切换，会在当前批次结束后应用。

点击已有 Logo 可移动、旋转和等比缩放，点击空白取消选择。按住鼠标或空格拖动画布，Alt＋滚轮缩放预览。按原格式、原文件名导出。

## 其他流程

- 制作详情页：选择模板、上传素材、插入图片，选择自适应或固定框后导出。单列图片超过 1 行、双列超过 2 行时，自动逐行裁剪为单列 1 图 / 双列 2 图；不足一行的尾图保留。多片当前页导出 ZIP，整套导出按页码和分片编号排序。编辑画布和未超阈值页面保持原样。
- 套详情图：上传素材和页面，批量套图或选页 AI 处理，确认后导出。
- AI 抠图：登录网站后启动自动处理，完成提示可点击关闭。
- AI 设置：Gemini API 统一模型，多 API 检测与限流轮询。

刷新保留本次内容；重新运行启动器开始空白工作。Logo 库、尺寸记忆与加密 API 设置保留。

64 位 Windows；Python 3.10 或更新版本（包括 3.14）；Edge / Chrome 120 或更新版本。缺失 Python 或组件可通过启动器安装，浏览器自行安装。故障运行「诊断启动器.bat」。

源码提示词：`patchi_ai_prompts.py`；API 池与调度：`patchi_ai.py`。本版 AI 和精准套图算法保持 2026.10.15.9 版。

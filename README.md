## 制作主图

上传颜色图与 Logo，首图贴标后批量同步，再逐张微调。支持位置、等比缩放、旋转、画布平移和 Alt＋滚轮缩放；画布可选 2500×2500 或原分辨率。

制作主图中的 Gemini AI 已移除。保留手动贴标、本地光影建议、原图保护画笔、逐图确认和撤销；按原格式原名导出。其他区域的 Gemini 功能沿用原有设置。

## 外部批量贴标

主页「外部批量贴标」 → 连接 ComfyUI → 读取主图贴标快照或直接上传 → 设置胸前 / 内侧领标 → 批量处理 → 逐图复核 → 原格式原名导出。

- 专用 `PatchiSticker` 节点，以原始 Logo 像素合成，不重画品牌文字。Depth Anything V2 Small 辅助局部褶皱与凸起，CLIPSeg 辅助领口、抽绳等遮挡，原衣料明暗和纹理参与光影融合。
- 同款相似构图按首图局部纹理做小幅位置与旋转校准。纹理不足或变动过大时保留手动位置，适用于辅助美工制作初稿。
- CPU 单张顺序处理，默认不使用老 AMD R7 1GB 显卡。适配 16GB 内存电脑；CPU 推理可能较慢，先做少量实图验收。可连接另一台机器的 ComfyUI。
- 实时查看阶段和检查记录，可立即停止本地等待，只取消自己的批次，不全局中断 ComfyUI。刷新恢复当前内容和任务，重新启动工坊开始新工作。
- 细抽绳、复杂或低反差领口仍可能漏检；需要逐图复核。勾选“已复核”后导出，改过位置的旧结果不能直接导出。外部成品独立保存，不覆盖主图编辑器。

### 安装与教程

1. 完整解压后运行 `安装外部贴标_CPU.bat`，安装独立的 ComfyUI、CPU PyTorch 和两个视觉模型，不修改工坊本体的 Python 环境。
2. 安装完成后运行 `外部贴标环境/启动外部贴标_CPU.bat`，保持控制台打开。
3. 工坊入口填 `http://127.0.0.1:8188`，点击保存检查。
4. 完整安装、已有便携版、远程连接、使用和故障排查：打开包内 [ComfyUI部署教程.html](ComfyUI部署教程.html)，或在工坊外部入口点击教程。

模型与 ComfyUI 不包含在 ZIP 中，安装时从官方源下载，需网络和至少 8GB 磁盘。已有 Python 3.14 可先使用；若外部 PyTorch 没有匹配 wheel，仅为外部环境选择兼容的 64 位 Python，工坊本体不必更换。

节点代码：[ComfyUI_PatchiSticker](ComfyUI_PatchiSticker)；[API 工作流模板](ComfyUI_PatchiSticker/workflow_api.json)；本机桥接：`patchi_comfy.py`。API 模板由接口自动填写，不是可直接拖入 ComfyUI 画布的 UI JSON。

参考 [Comfyui-Transform](https://github.com/LAOGOU-666/Comfyui-Transform) 的自由变换与参数继承思路。其 README 说明稳定后端非公开；本包未复制或解密其节点，适配代码独立实现。模型与第三方软件按各自许可证使用。

## 其他流程

- 详情页：选模板、上传素材、插入图片，选择自适应或固定框后导出。长图片页按既有规则逐行分片。
- 套详情图：白底或透明素材，批量套图或选页 AI，确认后导出。
- AI 抠图：网站登录后自动处理，完成提示可点击关闭。
- AI 设置：除主图外，各 Gemini 区域独立记忆模型，任务限流或权限不足时轮询 API。模型目录可见不代表实时额度。

工坊本体支持 64 位 Windows、Python 3.10 及更新版本（含 3.14）、Edge / Chrome 120 或更新版本。故障运行「诊断启动器.bat」。

接口和像素合成、浏览器流程、启动脚本已验证；模型识别使用模拟输出检查，尚未在用户的 Windows 电脑实测模型效果和速度，部署后需先用实际商品图验收。详见包内「验证说明.txt」。

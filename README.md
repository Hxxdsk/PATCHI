# 帕琪工坊

[下载完整程序包 2026.10.15.9](https://github.com/Hxxdsk/PATCHI/raw/refs/heads/main/downloads/%E5%B8%95%E7%90%AA%E5%B7%A5%E5%9D%8A_%E5%AE%8C%E6%95%B4%E6%9B%B4%E6%96%B0%E5%8C%85_2026.10.15.9.zip)

关闭旧 Python 助手，完整解压后双击 **帕琪工坊启动器.exe**。缺少环境可在启动器内下载安装。支持 64 位 Python 3.10 及以上（包括 3.14），使用桌面版 Edge / Chrome 120 或更新版本。打不开时运行「诊断启动器.bat」。

- **制作主图**：上传 Logo 和颜色图，在 2500×2500 画布放置、缩放、旋转；批量贴标后逐张微调，再进行褶皱、光影和遮挡 AI 处理。按原格式、原文件名导出。Logo 输入支持 128MB / 3200 万像素，原分辨率合成不受旧 5MB 限制。
- **制作详情页**：选择模板，图片选择自适应或固定框，点击文字编辑，完成后导出。
- **套详情图**：批量精准匹配，未识别处手动补充；可只 AI 处理当前页并撤回上一步 AI。
- **AI 抠图**：加入队列后可关闭窗口，完成时右上角提示。
- **AI 设置**：支持 `AQ.` 格式密钥。添加多个不同项目的 API 后，一次检测全部 API。检测会发起小型图像请求，仅列出检测时调用成功的模型；选择一个统一模型，轮询时保持该模型，跳过不兼容、无权限或额度受限的 API。
- **工作记忆**：刷新保留内容和未完成任务；重新运行启动器开始空白工作，长期 Logo 库、尺寸记忆和加密 API 设置保留。

模型检测会产生少量 API 用量；检测通过表示当时可用，实际额度随后可能变化。程序不推测账户剩余额度。查看 Google AI Studio 可核对项目配额。

使用方法见「开始使用.txt」与软件内教程。统一提示词在 `patchi_ai_prompts.py`，API 池与任务调度在 `patchi_ai.py`。

34 项自动检查和 Chromium 流程验证通过，包括超过 20MB 的 2500×2500 Logo 导入、AI 限流切换、刷新恢复和导出。在线响应使用模拟，实际账号权限、图像效果与 Windows EXE 运行仍需实机核对，详见「验证说明.txt」。

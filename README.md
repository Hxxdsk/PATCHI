本版更新：

- **Python 3.14 可直接使用**：支持 64 位 Python 3.10 及更新版本，不设置版本上限。组件也取消上限，较新且正常可用的版本会直接通过。
- **启动器界面更新**：深色卡片、运行环境／组件／浏览器状态、圆角按钮和工坊图标。
- **素材可删除**：套详情图素材右上角的 × 可删除不用的图，已套入的结果仍可撤销、保存和导出。
- **快速批量套图**：点击顶部“批量套图”，逐页遍历当前全部服装素材。图片特征只准备一次并复用，快速可靠的匹配先套入，其他位置留待手动点击补充。支持停止批量，重复运行避免重复叠加。
- 保留原文件名导出、无损 PNG 选项、不规则／镂空 Logo、原始分辨率及色差／轻微姿势适配。

支持 Windows 10／11 64 位。缺少 Python 或组件时可点击内置下载并安装；不会自动下载浏览器，需要已有桌面版 Edge 或 Chrome 120+（建议最新版）。

快速模式对每个组合使用约 1.8 秒的软识别预算，省略耗时模板搜索；图片准备、原生算法单次调用及原尺寸合成可能更久。未识别的位置选中素材后手动点击补充。批量结束后请复核位置、边缘和遮挡。

已通过 9 项图像／批量回归、实际浏览器的素材删除／全页遍历／停止／重复运行测试，以及原文件名导出测试。3 页 × 2 素材的合成样本批量实测约 3.3 秒，不代表所有大图或电脑。现代界面控件按 C# 5／.NET Framework 编译检查通过。

当前构建机为 Linux；真实 Windows 窗口显示、Python 3.14 环境及下载安装尚未实机验证。详见 [开始使用.txt](./开始使用.txt) 和 [验证说明.txt](./验证说明.txt)。

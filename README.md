## 制作主图

上传颜色图与 Logo，在画布贴标，第一张完成后批量贴标，再逐张微调、生成本地光影或 AI 真实贴合建议，逐张预览并应用后导出。

画布上方可随时选择「2500×2500」或「原分辨率」。原分辨率保留每张图完整宽高和透明边缘；2500 模式等比居中。切换时同步换算 Logo 位置、大小与保护笔画，旋转角度保留。AI 处理中选择切换，会在当前批次结束后应用。

本地光影融合保留且不耗 API。选择「AI 真实贴合」和主图独立模型后，其他批量颜色图先参考首图对应部位校准 Logo 位置、尺寸与旋转，再基于最终局部图处理衣领、抽绳遮挡、衣物边缘、褶皱网格和光影。以原始 Logo 像素合成，避免重新绘制品牌文字。未应用的建议不会导出；应用后可撤销，刷新与分辨率切换保留待确认建议。

点击已有 Logo 可移动、旋转和等比缩放，点击空白取消选择。按住鼠标或空格拖动画布，Alt＋滚轮缩放预览。按原格式、原文件名导出。

首图位置以用户贴标为准；跨颜色校准只用于通过「批量贴标」建立对应关系的图片。批次开始后固定模型，途中更改模型或刷新不会改变当前批次。参考颜色图通常包含定位和贴合两次请求，结果需逐张复核。

AI 任务窗口实时显示阶段、当前 API、等待时间和轮询记录，及时提示认证失效、权限与额度限制。可立即停止本地等待；已经提交的 API 可能仍在远端处理，迟到结果不会应用。等待时可切图、拖动缩放画布或返回工坊。模型拒绝结构化约束时尝试兼容 JSON；异常褶皱与不可靠的过度擦除建议保留原标识并提示。

## 其他流程

- 制作详情页：选择模板、上传素材、插入图片，选择自适应或固定框后导出。单列图片超过 1 行、双列超过 2 行时，自动逐行裁剪为单列 1 图 / 双列 2 图；不足一行的尾图保留。多片当前页导出 ZIP，整套导出按页码和分片编号排序。编辑画布和未超阈值页面保持原样。
- 套详情图：上传白底或透明 PNG / JPG / WebP 素材和页面，批量套图或选页 AI 处理，确认后导出。
- AI 抠图：登录网站后启动自动处理，完成提示可点击关闭。
- AI 设置：并行读取全部 Gemini API 模型目录，不逐模型测试；商品信息、尺码、细节文案、主图、套图 AI 及衣物轮廓各自选择并自动记忆模型。任务限流或权限不足时轮询 API，当前任务模型不变。目录可见不保证图像兼容、实时速率或剩余额度，实际调用时验证。

刷新保留本次内容；重新运行启动器开始空白工作。Logo 库、尺寸记忆与加密 API 设置保留。

64 位 Windows；Python 3.10 或更新版本（包括 3.14）；Edge / Chrome 120 或更新版本。缺失 Python 或组件可通过启动器安装，浏览器自行安装。故障运行「诊断启动器.bat」。

源码提示词：`patchi_ai_prompts.py`；API 池与调度：`patchi_ai.py`。

## 本次修复

- **EXE 无窗口／闪退**：复现旧脚本开头重复 UTF-8 BOM 导致 `param` 被当成命令、程序目录参数读入失败。修复编码，增加 PowerShell 启动监测、错误提示、启动日志及直接运行源码的诊断入口。
- **主图固定 2500×2500**：导入横图、竖图或方图后，等比例居中，长边贴到画布边缘，完整保留可见内容。透明图仅去除外围全透明空边；白底／JPG 按整个文件范围适配。PNG 和 JPG 均输出 2500×2500。
- **放置后取消选中**：每次选 Logo 放到画布后，取消库图高亮和编辑框，便于观察。点击已有 Logo 才显示编辑框，点击画布外或空白处取消选中。
- **默认鼠标平移**：未选中时按住鼠标拖动画布，包括在未选中的 Logo 上拖动。选中后拖图案移动 Logo，拖空白处平移。空格拖动仍可随时平移，Alt + 滚轮缩放预览。
- **旋转与大小**：选中 Logo 后拖上方圆形旋转柄，或输入角度；拖角点等比例缩放。旋转后仍可缩放，Shift 旋转以 15° 步进。
- **旧主图工程**：自动按图片的统一比例和居中偏移迁移到新画布，原始上传文件仍保存在工程里；加载后请复核布局。

## 保留的功能

精准套详情图与快速批量保持 2026.10.12.4 引擎：共同纹理确认位置、色差与轻微姿势适配、高分辨率原素材、不规则／镂空 Logo、原名导出、素材删除、停止及防重复叠层。跨姿势自动定位保持取消。

主图支持长期 Logo 库、尺寸记忆、按上传顺序切换颜色图、第一张批量同步、逐图微调、工程保存／恢复及撤销。PNG 保留透明，JPG 转白底；可按原文件基本名称或 01、02…导出 ZIP，同名文件分目录保存。

Gemini 主图处理复用已有设置，分析遮挡与光照，再用原 Logo 像素合成，不重新生成品牌，不降低原 Logo 透明度；可用原图保护画笔修正细部。失败保留手动结果，重试跳过已完成图，可完成当前图后停止。官方抠图 API 保持移除，免费浏览器自动与手动回收保留。

## 环境与说明

Windows 10／11 64 位，需要系统 Windows PowerShell 5.1 与 .NET Framework。支持 64 位 Python 3.10 及更新版本（包括 3.14），组件不设版本上限；已有高版本且功能正常时直接使用。缺少 Python／组件可点击内置安装；浏览器不自动下载，需要已有桌面版 Edge 或 Chrome 120+。

Logo 库存于当前浏览器、本机站点地址的 IndexedDB；退出不清空，清除站点数据或更换浏览器会影响收藏。颜色图与编辑结果请保存主图工程。

早期启动记录：`.runtime/launcher.bootstrap.log`；失败原因：`.runtime/launcher.failure.txt`。详细用法见 [开始使用.txt](./开始使用.txt)，源码在 [启动器源码](./启动器源码)。

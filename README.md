## 本次更新

- **取消跨姿势功能**：移除跨姿势自动定位、Logo 框选与三点校准。套详情图和快速批量恢复 2026.10.12.4 的精准匹配引擎，两份引擎文件与旧版逐字节一致。
- **新增制作主图入口**：左侧长期 Logo 库，右侧按上传顺序切换同款不同颜色图，中间画布贴标。选 Logo 后点击画布放置，拖动位置、角点等比例缩放或输入数值，可调整角度。
- **尺寸自动记忆**：每个 Logo 记忆相对主图宽度的尺寸，下一款继续复用。退出不清空 Logo 库，可点击删除；已贴入的 Logo 保留。
- **画布操作**：Alt + 滚轮以鼠标为中心缩放；空格 + 拖动平移。仅改变预览，不改变贴标坐标和导出尺寸。
- **批量贴标与微调**：将第一张全部 Logo 的位置、大小和角度同步到其他上传图；不同画布按比例换算，随后可以逐张独立调整。此同步适合同构图的同款颜色图。
- **Gemini 主图处理**：复用已有 API 设置。逐张分析领口、抽绳等前景遮挡和衣服光照，返回轮廓与光影参数，再用原始 Logo 像素在本机合成，保持文字、图案、原透明度。只有真实遮挡区域恢复原衣服像素，光照只改颜色，不把 Logo 整体变透明。可用原图保护画笔修正细部。
- **批量导出**：PNG 保留透明背景，JPG 转白底；可保留原文件基本名称或按导入顺序 01、02…命名。同名文件分目录，保持原图尺寸，附处理报告。
- **工程与失败恢复**：主图可保存／读取工程，撤销调整。AI 失败保留手动贴标，重试跳过已有结果；可完成当前图后停止。
- 官方抠图 API 保持移除，保留免费浏览器自动操作和手动回收。原文件名套图导出、素材删除、高清不规则 Logo、色差与轻微姿势适配、现代深色启动器继续保留。修复缺组件时 pip 的 requirements 路径参数。

## 使用要求

Windows 10／11 64 位；支持 64 位 Python 3.10 及更新版本（包括 3.14），组件不设置版本上限。已有环境可正常导入并具备所需功能时直接使用。缺少 Python／组件时点击内置下载并安装；浏览器不自动下载，需要已有桌面版 Edge 或 Chrome 120+，建议最新版。

Logo 库位于当前浏览器、当前本机站点地址的 IndexedDB。退出软件不清空；清除站点数据、隐私模式或更换浏览器可能影响收藏，建议保留 Logo 源文件。颜色图与编辑结果请保存主图工程。

AI 处理会把原图、贴标预览及局部区域发送至 Google Gemini，费用、配额与模型权限以自己的项目为准；密钥不会写入主图工程。接口参考 [Google 官方 generateContent 文档](https://ai.google.dev/api/generate-content)。

详情见 [开始使用.txt](./开始使用.txt)，源码在 [启动器源码](./启动器源码)。

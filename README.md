# 帕琪工坊

关闭旧 Python 助手，完整解压后双击 **帕琪工坊启动器.exe**。缺少环境可在启动器内下载安装。支持 64 位 Python 3.10 及以上（包括 3.14），使用桌面版 Edge / Chrome 120 或更新版本。打不开时运行「诊断启动器.bat」。

- **制作主图**：上传 Logo 和颜色图，在 2500×2500 画布放置、缩放、旋转；第一张完成后批量贴标、逐张微调，再进行褶皱、光影和遮挡 AI 处理。按原格式、原文件名导出。
- **制作详情页**：上传素材、选择模板，图片选择自适应或固定框，点击文字编辑，完成后导出。
- **套详情图**：使用已贴标透明服装图批量精准套入详情页，未匹配处手动补充；可只 AI 处理当前页并撤回上一步 AI。
- **AI 抠图**：加入队列后可关闭窗口，完成时右上角提示；失败可手动回收透明 PNG。
- **AI 设置**：集中管理所有 Gemini 功能和多个 API；同项目填写相同分组，共享限额冷却，限流时切换兼容 API。完整模型列表来自当前 API；未知速率和剩余额度显示「—」，实际额度在 Google AI Studio 查看。
- **工作记忆**：刷新保留内容和未完成任务；重新运行启动器开始空白工作，长期 Logo 库、尺寸记忆和加密 API 设置保留。素材库支持一键清空。

使用方法见「开始使用.txt」与软件内教程。统一提示词在 `patchi_ai_prompts.py`，API 池和任务调度在 `patchi_ai.py`。

## 制作主图

上传颜色图与 Logo，首图贴标后批量同步，再逐张微调。支持位置、等比缩放、旋转、画布平移和 Alt＋滚轮缩放；画布可选 2500×2500 或原分辨率。

生成本地光影建议，逐张预览后应用，可撤销；细部遮挡用原图保护画笔修正。按原格式、原文件名导出。主图不调用 Gemini。

## 其他流程

- 详情页：选模板、上传素材、插入图片，选择自适应或固定框后导出。长图片页按既有规则逐行分片。
- 套详情图：白底或透明素材，批量套图或选页 AI，确认后导出。
- AI 抠图：网站登录后自动处理，完成提示可点击关闭。
- AI 设置：各 Gemini 区域独立记忆模型，任务限流或权限不足时轮询 API。模型目录可见不代表实时额度。

刷新保留本次内容；重新运行启动器开始空白工作。Logo 库、尺寸记忆与加密 API 设置保留。

支持 64 位 Windows、Python 3.10 及更新版本（含 3.14）、Edge / Chrome 120 或更新版本。缺少 Python 或组件时可通过启动器安装，浏览器自行安装。故障运行「诊断启动器.bat」。

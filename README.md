本版更新：

- **跨姿势套详情图**：针对领口、中央拉链、衣身分区清楚的正面羽绒服／夹克，按衣服结构映射 Logo 的位置与大小。支持大图黑底／透明素材到小图白底、袖子与帽领姿势略有变化的情况，只迁移独立 Logo，保留目标衣料、褶皱和背景。
- **Logo 标记与位置校准**：彩色徽标尝试自动提取；单色或提取困难时可框选 Logo、预览透明提取结果，再用三个对应结构点校准。标记随工程保存。
- **快速批量套图**：逐页遍历全部当前素材，缓存纹理、衣身结构及独立 Logo。可靠匹配先套入，结构不足或多个素材难以区分时跳过，留待手动补充。可停止、继续，重复运行避免重复叠层。
- **取消抠图官方 API**：移除 API 模式、密钥输入、开发者入口和后端代理；保留免费网站浏览器自动操作与手动回收。商品信息、表格与详情文案的 Gemini 设置保留。
- 保留原文件名导出、无损 PNG 选项、原始尺寸、不规则／镂空 Logo、高分辨率原素材采样、色差适配、素材删除及现代深色启动器。

支持 Windows 10／11 64 位，Python 3.10 及更新版本（包括 3.14），组件不设置版本上限；已有环境能正常导入且具备所需功能时直接通过。缺少 Python 或组件时可点击内置下载并安装。浏览器不自动下载，需要已有桌面版 Edge 或 Chrome 120+，建议最新版。

自动结构匹配主要针对正面羽绒服／夹克，不能仅凭外观确认商品身份。其他服装或视角可使用 Logo 标记与三点校准。批量结束后请复核位置、边缘和遮挡；目标图维持原尺寸，小图中的 Logo 也受原像素数量限制。

快速模式为每个组合设约 1.8 秒软识别预算，不做耗时模板搜索；图片准备、单次原生算法和原尺寸合成可能更久。未识别的位置可选中素材后手动补充。

已通过 16 项图像／跨姿势／批量回归，以及实际 Chromium 的自动匹配、预览提取、标记保存、三点校准、批量遍历／停止／重复运行、素材删除、原文件名导出和 API 移除检查。PowerShell 状态逻辑通过，64 位 Windows EXE 已编译并核对内嵌脚本。
